# DeepSeek 执行模板

Task ID / Title / Goal / Dependencies / Context / Files / Implementation Requirements / Visual Specification / Data & API Contract / Constraints / Acceptance Criteria / Test Commands / Expected Deliverables / Failure Conditions / Definition of Done / DeepSeek Execution Prompt 必须全部填写。

执行前逐项核验依赖accepted，读取白名单外文件可以，修改仅限Files。先报告契约冲突，不自行重定义。完成时提交：实际模型/任务ID、变更文件、理由、命令+exit code、测试输出、截图与复现URL、已知缺陷。不能写“应该通过”；无法运行写NOT_RUN及原因。状态进入review，不自行accepted。

修复模板：FIX-<task>-<n>；复现步骤；实际结果；预期规范具体条目；截图路径与区域；允许改文件；测试命令；完成证据；是否触发其他页面回归。
