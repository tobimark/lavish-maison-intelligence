# 主控审查记录模板

- Task / 实际执行模型 / 代码commit或hash / 依赖状态
- 目标行为与契约：满足/不满足及证据
- 文件范围：是否越界、是否改公共契约、是否引入未经审查的视觉值
- 数据：来源、幂等、状态机、版本、时区、隔离
- 测试：真实命令、exit code、失败及范围
- 前端：实际URL、浏览器/字体/视口、已打开截图路径、逐项对照DESIGN_SYSTEM与页面规格
- 问题：优先级、复现、预期、负责FIX任务
- 结论：changes_requested / accepted；主控签署；阶段门禁需PO体验决定

里程碑Checklist：所有任务accepted、必需测试通过、视觉证据完整、未解决缺陷显式列出、文档契约一致、下一阶段解锁记录。M1未通过则后续保持locked。
