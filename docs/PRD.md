# 需求审查与产品基线

版本 0.1 · 2026-11-03 · 原始需求与本轮视觉更新合并。

## 产品目标

为 Lavish Perfumes 演示可追溯市场机会如何转化为可编辑 Campaign、双语创意、可下载图像与 15 秒 MP4，再进入版本审批、排期、模拟发布和统一反馈。Presentation First 不意味着前端假动画：后台任务、状态转换、关联关系和导出文件必须真实工作。

## 完整成功条件

- Scenario A 在 5–8 分钟走完 Signal → Trend → Opportunity → Campaign → Assets → Approval → Calendar → Simulated Feedback。
- 后台 Autonomous Demo Feed 关闭浏览器后继续；Presentation Replay 使用独立命名空间，支持暂停、步进、1/2/4 倍速、跳转、重播、恢复与多会话隔离。
- 同一事件流到相同虚拟时间的业务投影哈希一致；仅用户主动 Create Campaign 才落持久业务对象。
- 修改/生成有不可变版本；审批和排期指向精确版本；已批准内容不被覆盖。
- AI 预置模式离线可用，真实模型失败明确报错，用户可显式切换预置模式。
- 真实渲染 1080×1920、9:16、15 秒、四镜头 MP4，英文/阿文字幕、片尾、封面和下载均可检验。
- 所有 Demo 数据、模型预置结果和模拟发布均有清晰标识与统一来源。
- M1 核心原型先通过主控视觉审查与 Product Owner 体验审查；后续页面逐页执行同一门禁。
